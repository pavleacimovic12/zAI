# Clinical Research AI Assistant 🩺

An advanced **OpenAI GPT-4o powered** assistant for clinical research coordination and medical knowledge, built with Streamlit for seamless deployment on Posit Connect.

## 🚀 Key Features

### 🧠 **ChatGPT-Like Intelligence**
- **OpenAI GPT-4o Integration**: Comprehensive, flexible responses to any clinical research question
- **5-Exchange Memory System**: Maintains conversation context for natural dialogue flow
- **Professional Expertise**: Specialized system prompts for clinical research coordination

### 🎨 **Beautiful Design**
- **Purple Gradient Theme**: Professional medical interface with glass-morphism effects
- **Enhanced Animations**: Floating elements, glow effects, and smooth transitions
- **High Contrast**: Optimized text visibility and accessibility
- **Responsive Layout**: Works perfectly on all devices

### 📁 **Advanced Document Support**
- **15+ File Types**: PDF, Word, Excel, PowerPoint, images, text files, and more
- **AI-Powered Analysis**: Upload documents for intelligent analysis and discussion

### 🏥 **Clinical Research Expertise**
- **Drug Treatments**: Comprehensive information on medications for all conditions

## 🚀 Deployment Instructions

### Step 1: GitHub Upload
1. Create a new GitHub repository
2. Upload the 5 files listed above
3. Commit and push to main branch

### Step 2: Posit Connect Deployment
1. **Login** to your Posit Connect account
2. **Click** "New Content" → "Deploy from Git"
3. **Select** your GitHub repository
4. **Choose Framework**: Select **"Streamlit"**
5. **Environment Variables**: Add `OPENAI_API_KEY` (optional for enhanced responses)
6. **Deploy**: Click deploy and get your custom URL

### Step 3: Configuration
- **Python Version**: 3.8+ (automatically detected)
- **Dependencies**: Automatically installed from requirements.txt
- **Memory**: Maintains 5-exchange conversation history
- **Performance**: Optimized for fast response times
