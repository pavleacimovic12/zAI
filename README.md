# Clinical Research AI Assistant - Streamlit Version

A Streamlit-based AI assistant for clinical research and medical knowledge, optimized for Posit Connect deployment.

## Features

- Comprehensive medical knowledge for MS, Alzheimer's, Parkinson's, diabetes
- Clinical trial design and regulatory guidance
- Beautiful medical-themed interface with custom styling
- No external API dependencies required
- Interactive chat interface with conversation history

## Files for GitHub Upload

Upload ALL these files to your GitHub repository:

1. `app.py` - Main Streamlit application
2. `requirements.txt` - Dependencies (Streamlit only)
3. `.streamlit/config.toml` - Streamlit configuration
4. `README.md` - This documentation

## Posit Connect Deployment

1. Upload files to GitHub repository
2. In Posit Connect, select "Streamlit" as framework
3. Connect to your GitHub repository
4. Deploy automatically

The application will run on Streamlit's default port (8501) and provide comprehensive medical knowledge without requiring any external API keys.
